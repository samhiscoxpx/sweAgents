# Hazards

Engine quirks, tool blind spots and shared-machine effects, with no fix for us to make. Read this file
before diagnosing a failing run that looks unrelated to your change. A hazard we can fix is a defect and
goes in `<defect-register>` instead.

## <subject: the engine, tool or machine effect, in a few words>

What happens, in one sentence, and the condition that triggers it.

- [<date>, <where seen>] One dated sighting per line: what was seen, the command or check that shows it,
  and the workaround. Run the check once against a known positive input before you record it.
