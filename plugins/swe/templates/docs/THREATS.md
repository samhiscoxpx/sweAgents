# Threats

What an attacker reaches, what stops them, and what is left over. The Co-CTO checks a security
boundary claim against this document and the tree before sending it.

## Who can call us

Each kind of caller and the entry points it reaches, authenticated or not.

## What each caller must not reach

The data or operations outside each caller's scope, and what a leak of each would cost.

## What stops them

For each threat, the control and the file and line that enforces it.

## What is left over

Each accepted residual with its register entry in `<defect-register>` or `<deferred-feature-register>`.
